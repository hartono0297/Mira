Perbandingan stack Mira

22 November 2026 · Diukur langsung di PC pengembangan proyek ini

Semua angka di dokumen ini hasil pengukuran sungguhan dengan aplikasi contoh kosong, bukan perkiraan atau angka dari internet. Aplikasi Mira yang lengkap akan lebih besar dan memakai lebih banyak memori, tapi perbandingan antar pilihan tetap berlaku.

Keputusan untuk sekarang: pembangunan memakai stack di rencana pembangunan, yaitu Tauri dengan React dan TypeScript, sesuai instruksi 22 November 2026. Dokumen ini menjadi bahan kalau stack ingin ditinjau ulang.

Memori = private bytes, dijumlah dari semua proses aplikasi. Render diukur di dalam WebView2 aplikasi Tauri, rata-rata 3 kali. "Memori kosong" untuk React, Svelte, dan Solid memakai angka Tauri tanpa kerangka, karena tampilan kosong ketiganya praktis sama kecilnya.

Artinya

  1. Di dalam Tauri, beda React, Svelte, dan Solid kecil. Saat menampilkan 5.000 baris, React memakai sekitar 8 sampai 9 MB memori lebih banyak dan sekitar 30 ms lebih lambat. Untuk mengubah sebagian baris, ketiganya hampir sama cepat.
  2. Sebagian besar memori dipakai WebView2. Aplikasi Tauri kosong saja sudah memakai sekitar 157 MB yang tersebar di 7 proses. Pilihan kerangka tampilan hanya menggeser angka ini sedikit.
  3. Rust native jauh lebih ringan hanya kalau memakai renderer software. Slint dengan renderer software cuma memakai sekitar 5 MB dan jendelanya muncul dalam 130 ms. Dengan renderer GPU bawaannya, memorinya justru setara Tauri karena driver grafis ikut memesan memori.
  4. Ukuran installer Tauri sangat kecil: 1,34 MB untuk installer NSIS. Program Slint lebih besar (11,70 MB) karena mesin gambarnya ikut di dalam program.

Dibuat dengan create-vite (template react-ts, svelte-ts, solid-ts, vanilla-ts), React 19 dan Solid 1.9. Karena aplikasi dimuat dari disk laptop dan bukan dari internet, selisih ukuran ini hampir tidak terasa oleh pengguna.

2. Kecepatan menampilkan daftar panjang

Setiap tampilan merender 5.000 baris pesan (seperti chat panjang), lalu mengubah 500 di antaranya. Waktu sudah termasuk tata letak halaman. Svelte memakai $state.raw, cara yang disarankan untuk daftar besar.

Cara pengukuran

  • PC: Windows 11 Home, Node.js 22, Rust 1.99, Chrome terpasang, WebView2 bawaan Windows.
  • Tampilan dibuat dengan create-vite dan di-build oleh Vite untuk produksi.
  • Aplikasi Tauri dibuat dengan create-tauri-app (Tauri 2), dibangun dalam mode release. Setiap varian tampilan dimasukkan ke aplikasi yang sama lalu dibangun ulang.
  • Aplikasi Slint memakai Slint 1 dalam mode release, dengan satu jendela, dua teks, dan satu tombol.
  • Memori diukur sebagai private bytes dari semua proses milik aplikasi, 8 detik setelah dibuka. Working set tidak dipakai, karena menjumlahkannya antar proses menghitung memori bersama berkali-kali.
  • Kecepatan di Chrome diukur dengan puppeteer-core, Chrome headless, dan garbage collection dipaksa sebelum membaca memori.
  • Semua aplikasi contoh disimpan di folder sementara dan bukan bagian dari kode Mira.
Angka bisa berbeda di laptop lain, tergantung prosesor, driver grafis, dan versi WebView2. Yang paling bisa dipegang adalah perbandingan antar pilihan, bukan angka mutlaknya.
