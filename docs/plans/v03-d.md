# Rencana v0.3 bagian D: anggota proyek, dokumen proyek, angka notifikasi

Tanggal: 23 November 2026. Dasar: `main` 07361fa (fondasi v0.3). Kontrak: `docs/plans/v0.3-kontrak.md`. Mockup: `design/usulan-v0.3.html` bagian 5 dan 6 (opsi C).

## 1. Lingkup

1. Anggota proyek di board: dialog Proyek baru dengan departemen dan pemilih orang, izin membuat proyek, panel Anggota proyek, penanggung jawab hanya anggota proyek, penjelasan untuk orang yang dikeluarkan, superadmin bergabung sendiri, muat ulang lewat `mira://directory` dan `mira://feature` topik board.
2. Dokumen per proyek: pilihan lokasi (Pustaka Umum atau proyek) untuk melihat dan menambah file.
3. Angka notifikasi (opsi C) di sidebar dan daftar proyek, dihitung lokal.
4. Uji ujung ke ujung yang terdampak.

Tidak disentuh (kontrak bagian 9): `permissions/`, `board/access.rs`, `board/membership.rs`, `db/migrations.rs`, `org_commands.rs`, `src/api/org.ts`, `device.rs`, `chat/`, `src/screens/chat/`, `network/`, onboarding, halaman Organisasi. Tidak ada migrasi baru.

## 3. Kontrak tampilan (dipakai uji ujung ke ujung)

- Dialog "Proyek baru": `Nama proyek`, `Kode proyek`, select `Departemen` (opsi nama departemen dan `Tanpa departemen`), pemilih orang dengan kotak cari berlabel `Cari nama`, tombol saringan `Semua` dan nama departemen (`aria-pressed`), kotak centang per orang dengan nama orang sebagai nama aksesibelnya. Baris pembuat tetap: "Anda, pengelola". Tombol `Buat proyek`.
- Kepala board: tombol berawalan `Anggota` (misalnya "Anggota, 4 orang"). Panel "Anggota proyek" berupa dialog. Tombol `Tambah anggota` membuka pemilih yang sama dengan tombol `Tambahkan`. Tombol keluarkan: `Keluarkan <nama> dari proyek`. Untuk diri sendiri: `Keluar dari proyek`.
- Superadmin: bagian `Proyek lain` di navigasi board dengan tombol `Gabung ke proyek ini`.
- Sidebar: angka di `.side-count` di dalam tombol menu; nama tombol menjadi "Chat, 3 belum dibaca". Skrip uji mencari tombol menu dengan regex `^Nama(,|$)`, bukan `exact`.
- Dokumen: select `Lokasi` dengan opsi `Pustaka Umum` dan `<KODE> <nama proyek>`.
